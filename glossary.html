FaaS (Function as a Service) Вычисления

Модель бессерверных вычислений, при которой разработчик пишет атомарный фрагмент бизнес-логики (функцию), исполняемый облачной платформой по внешнему событию с посекундной тарификацией.

BaaS (Backend as a Service) Сервисы

Предоставление готовых функциональных блоков бэкенда в виде управляемых облачных сервисов: аутентификация (Cognito, Auth0), базы данных (DynamoDB, Firestore), объектные хранилища (S3) и очереди.

API Gateway Сетевой шлюз

Управляемый сервис-шлюз, выступающий единой точкой входа для клиентских HTTP/WebSocket запросов. Обеспечивает маршрутизацию, авторизацию по JWT, rate limiting, трансформацию данных и защиту от DoS.

Cold Start (Холодный старт) Производительность

Задержка при первом вызове функции после периода неактивности. Включает время выделения изолированного контейнера или MicroVM, загрузку кода и инициализацию среды выполнения (Node.js/Python).

Warm Start (Тёплый старт) Производительность

Повторный запуск функции на уже активном («прогретом») контейнере. Выполняется практически мгновенно (5–20 мс), так как среда выполнения и открытые сетевые подключения уже инициализированы.

Event-driven Architecture (EDA) Архитектура

Событийно-ориентированная архитектура, в которой компоненты системы взаимодействуют исключительно через создание, обнаружение и асинхронное потребление событий (Events).

Runtime (Среда выполнения) Платформа

Программная среда, предоставляемая облаком для исполнения кода функции на определённом языке программирования (например, Node.js 20.x, Python 3.12, Java 21, .NET 8).

Cloud Computing (Облачные вычисления) Инфраструктура

Модель предоставления повсеместного и удобного сетевого доступа по требованию к пулу конфигурируемых вычислительных ресурсов (серверы, накопители, сети и сервисы) через Интернет.

Stateless (Без сохранения состояния) Паттерн

Принцип проектирования, при котором каждый вызов функции изолирован и не зависит от предыдущих вызовов. Все персистентные данные хранятся во внешних BaaS базах.

MicroVM (Микровиртуальная машина) Виртуализация

Ультра-легковесная виртуальная машина (например, Firecracker от AWS), запускающаяся за 5 миллисекунд и обеспечивающая изоляцию безопасности уровня гипервизора при расходе памяти всего в несколько мегабайт.

Concurrency (Параллелизм вызовов) Масштабирование

Количество экземпляров функции, одновременно выполняющих запросы в конкретный момент времени. Регулируется квотами облачного провайдера для контроля расходов.

Vendor Lock-in (Привязка к вендору) Риски

Ситуация зависимости архитектуры от проприетарных технологий одного облачного провайдера, делающая миграцию на другую платформу финансово или технически трудоёмкой.

Provisioned Concurrency Оптимизация

Механизм предварительного прогрева заданного числа экземпляров функций в облаке, гарантирующий полное отсутствие холодного старта при всплесках пользовательского трафика.

Edge Computing (Периферийные вычисления) Edge

Выполнение бессерверного кода не в центральном дата-центре, а на серверах CDN в сотнях городов по всему миру рядом с конечным пользователем (Cloudflare Workers, Fastly Compute).
