Облачные платформы Serverless

Детальный разбор ключевых игроков облачного рынка: особенности среды исполнения, лимиты, поддерживаемые языки программирования и сценарии применения.

Ведущие бессерверные экосистемы

Сегодня практически каждый крупный облачный провайдер предлагает собственные решения в классе FaaS. Выбор конкретной платформы обычно определяется существующим стеком компании, требованиями к задержке (Latency), географией пользователей и законодательными нормами (например, 152-ФЗ в РФ).

Интерактивный каталог платформ

Переключайтесь между вкладками, чтобы изучить специфику и технический стек каждой платформы:

Amazon Web Services: AWS Lambda

Пионер индустрии с 2014 г.

AWS Lambda — эталонная и наиболее зрелая бессерверная платформа в мире. Предлагает максимальную интеграцию с более чем 200 сервисами AWS (S3, DynamoDB, SQS, SNS, EventBridge, Kinesis).

Ключевые возможности:

  • Среда изоляции: Технология MicroVM Firecracker.
  • Максимальное время выполнения: 15 минут на один вызов.
  • Выделяемая память: От 128 МБ до 10 240 МБ (10 ГБ), с пропорциональным выделением vCPU.
  • Поддерживаемые рантаймы: Node.js, Python, Java, Go, .NET, Ruby, а также поддержка Custom Runtime и OCI-контейнеров (Docker).
  • Оптимизация: Provisioned Concurrency для гарантированного отсутствия холодного старта.

Официальная документация: docs.aws.amazon.com/lambda ↗

Microsoft Azure Functions

Корпоративный стандарт

Azure Functions — мощное решение от Microsoft, ориентированное на бесшовную интеграцию с Active Directory, Office 365, Cosmos DB и средой .NET.

Ключевые возможности:

  • Durable Functions: Встроенный фреймворк для написания stateful-воркфлоу, оркестрации функций и ожидания внешних событий с сохранением прогресса.
  • Поддерживаемые рантаймы: C# (.NET), JavaScript/TypeScript, Python, Java, PowerShell.
  • Гибкость хостинга: Возможность запуска как в режиме Consumption (чистый serverless), так и на выделенных App Service планах или локально в Kubernetes через KEDA.

Официальная документация: learn.microsoft.com/azure/azure-functions ↗

Google Cloud Functions (2nd Gen)

Синергия с Cloud Run

Google Cloud Functions — сервис вычислений от Google. Во втором поколении построен поверх Cloud Run и Knative, что превращает каждую функцию в стандартный совместимый OCI-контейнер.

Ключевые возможности:

  • Параллелизм (Concurrency): До 1000 параллельных запросов на один экземпляр функции (в отличие от модели 1 запрос = 1 экземпляр в традиционном FaaS).
  • Максимальное время выполнения: До 60 минут для HTTP-триггеров.
  • Интеграция: Прямая связь с BigQuery, Cloud Pub/Sub, Firebase и AI-моделями Google Vertex AI.

Официальная документация: cloud.google.com/functions/docs ↗

Cloudflare Workers

Периферийные вычисления (Edge)

Cloudflare Workers — революционная пограничная FaaS-платформа. Код выполняется не в централизованных дата-центрах, а более чем в 300 городах по всему миру в непосредственной близости к пользователю.

Ключевые возможности:

  • Нулевой холодный старт: Используются V8 Isolates, время инициализации составляет менее 5 миллисекунд.
  • Низкая задержка: Запрос обрабатывается ближайшим узлом CDN сети.
  • Встроенные хранилища: Workers KV (key-value), D1 (serverless SQL SQLite), R2 (S3-совместимое объектное хранилище без платы за исходящий трафик).
  • Поддерживаемые рантаймы: JavaScript, TypeScript, WebAssembly (Rust, C++, Go).

Официальная документация: developers.cloudflare.com/workers ↗

Yandex Cloud Functions

Российская инфраструктура

Yandex Cloud Functions — отечественная масштабируемая бессерверная платформа, серверы которой расположены в российских дата-центрах с полным соответствием закону 152-ФЗ.

Ключевые возможности:

  • Бесплатный грант: 1 000 000 вызовов каждый месяц в рамках Free Tier.
  • Интеграция с YDB: Высокопроизводительная распределённая бессерверная СУБД с поддержкой строгих ACID-транзакций.
  • Экосистема триггеров: Триггеры таймера (cron), очереди Message Queue, события Object Storage, шина данных Data Streams.
  • Поддерживаемые рантаймы: Node.js, Python, Go, Java, PHP, Bash.

Официальная документация: yandex.cloud/ru/docs/functions ↗

Статистика рынка

По данным отчёта Datadog «State of Serverless», более 70% организаций, использующих AWS, применяют Lambda в продакшене. При этом на Node.js и Python приходится свыше 80% всех развёрнутых функций.
