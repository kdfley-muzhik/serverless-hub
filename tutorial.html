Практика: Создание первой Serverless функции

Пошаговое руководство по разработке и отладке бессерверного микросервиса на JavaScript (Node.js). Изучите структуру Handler, формат событий Event и протестируйте код прямо в браузере.

О практическом уроке

Для освоения бессерверного программирования не требуется привязывать банковскую карту или регистрироваться в платных облачных сервисах. Вся концепция FaaS строится на стандартной функции-обработчике (Handler), принимающей два аргумента:

  • event — JSON-объект с данными входящего запроса (HTTP-метод, заголовки, query-параметры, тело запроса).
  • context — служебный объект среды исполнения (ID вызова функции, оставшееся время таймаута, лимиты памяти).

Шаг 1. Подготовка структуры проекта

Создайте локальную папку для нашего микросервиса. Минимальная структура состоит всего из одного файла кода:

Файловая структура 
my-serverless-service/
├── handler.js        // Код функции-обработчика
├── package.json      // Манифест зависимостей Node.js
└── test-event.json   // Локальный тестовый JSON-запрос

Шаг 2. Написание кода функции (handler.js)

Наш микросервис обрабатывает входящие HTTP-запросы к каталогу товаров (/api/items): поддерживает чтение (GET) и добавление новых записей (POST):

JavaScript (handler.js) 
/**
 * Serverless Handler — Обработчик HTTP-запросов API Gateway
 * @param {Object} event - Объект события от API Gateway
 * @param {Object} context - Контекст выполнения функции в облаке
 * @returns {Promise<Object>} HTTP Response со статус-кодом, заголовками и телом
 */
exports.mainHandler = async (event, context) => {
  console.log(`[INFO] Получен вызов. Request ID: ${context?.awsRequestId || 'local-test'}`);

  // 1. Извлечение HTTP-метода и пути запроса
  const httpMethod = event.httpMethod || event.requestContext?.http?.method || 'GET';
  const path = event.rawPath || event.path || '/';

  // 2. Стандартные CORS-заголовки ответа
  const responseHeaders = {
    'Content-Type': 'application/json',
    'Access-Control-Allow-Origin': '*',
    'Access-Control-Allow-Headers': 'Content-Type,Authorization'
  };

  try {
    // 3. Обработка GET-запроса на получение списка
    if (httpMethod === 'GET' && path === '/api/items') {
      const itemsList = [
        { id: 1, name: 'Бессерверная функция A', type: 'FaaS' },
        { id: 2, name: 'Очередь сообщений SQS', type: 'Queue' }
      ];

      return {
        statusCode: 200,
        headers: responseHeaders,
        body: JSON.stringify({
          success: true,
          count: itemsList.length,
          data: itemsList
        })
      };
    }

    // 4. Обработка POST-запроса на добавление элемента
    if (httpMethod === 'POST' && path === '/api/items') {
      const payload = event.body ? JSON.parse(event.body) : {};
      
      if (!payload.name) {
        return {
          statusCode: 400,
          headers: responseHeaders,
          body: JSON.stringify({ success: false, error: 'Поле "name" обязательно' })
        };
      }

      return {
        statusCode: 201,
        headers: responseHeaders,
        body: JSON.stringify({
          success: true,
          message: 'Запись успешно создана в BaaS базе',
          createdItem: { id: Date.now(), name: payload.name }
        })
      };
    }

    // 5. Обработка несуществующих маршрутов (404)
    return {
      statusCode: 404,
      headers: responseHeaders,
      body: JSON.stringify({
        success: false,
        error: `Маршрут ${httpMethod} ${path} не найден`
      })
    };

  } catch (error) {
    console.error('[ERROR] Ошибка выполнения хендлера:', error);
    return {
      statusCode: 500,
      headers: responseHeaders,
      body: JSON.stringify({ success: false, error: 'Internal Server Error' })
    };
  }
};

Шаг 3. Формат входного события (Event) и ответа (Response)

Входной объект формируется API Gateway и содержит полную информацию о клиенте:

Вход: event.json 
{
  "rawPath": "/api/items",
  "requestContext": {
    "http": {
      "method": "GET",
      "sourceIp": "192.168.1.1"
    }
  },
  "headers": {
    "user-agent": "Browser/1.0"
  },
  "queryStringParameters": {
    "limit": "10"
  }
}
Выход: response.json 
{
  "statusCode": 200,
  "headers": {
    "Content-Type": "application/json",
    "Access-Control-Allow-Origin": "*"
  },
  "body": "{\"success\":true,\"count\":2}"
}
